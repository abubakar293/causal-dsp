# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or numerical flaw in `causal-dsp` (including numerical instability, lookahead leakage, division-by-zero vulnerability, or proof unsoundness), please report it responsibly by contacting the maintainer:

- Email: `abubakar293@users.noreply.github.com`
- GitHub Security Advisory: Open a private security report under the repository's "Security" tab.

Please include:
1. Detailed description of the vulnerability.
2. Steps or deterministic test scripts to reproduce the issue.
3. Impact assessment on production time-series pipelines or execution invariants.

We take security seriously and will acknowledge receipt within 48 hours and provide patches promptly.
